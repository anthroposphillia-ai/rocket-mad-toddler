# 로켓 매드 토들러 — 종합 MICE 대행사 홈페이지

**주소**: https://anthroposphillia-ai.github.io/rocket-mad-toddler/

## 디자인 컨셉: 고대 이집트 벽화 시스템 (팔레트 + 구조)

이시스 도상을 참고하되, **신 이미지(도상)는 넣지 않고** 색·구조·문양만 가져온 절충안입니다.

| 이집트 벽화 원리 | 웹 구현 |
|---|---|
| 등록선 (register) | 섹션을 가로 띠로 나눔 + 가는선-굵은선-가는선 이중 구분선 (`.band-rule`) |
| 색의 상징성 | 청금석 블루 `#1f4e8c` · 황금 `#cf9f2e` · 테라코타 `#a8442a` · 파피루스 크림 `#efe1c2` |
| 평면성 | 그림자·그라데이션 전면 금지. 2px 검정 윤곽선과 평평한 색면만 사용 |
| 상형문자 세로 배열 | 섹션 라벨을 세로쓰기로 (`.vlabel`, `writing-mode: vertical-rl`) |
| 공포의 공백 | 연꽃 보더(`.lotus`) · 지그재그 보더(`.zigzag`)로만 채움 |
| 비례 규범 | 카드 간격을 2px 격자로 통일 |

**타이포**: 제목 **나눔명조 800** (돌에 새긴 느낌) + 본문 Pretendard.

**의도적으로 넣지 않은 것**: 뿔 달린 태양 원반, 티엣(이시스의 매듭), 상형문자. 신 이미지는 실제 숭배 대상이라 기업 사이트에 부적절하다고 판단했습니다.

## 파일 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 전체 페이지 (제1~6띠: 히어로/소개/서비스/프로세스/실적/문의) |
| `style.css` | 디자인 전체 — 맨 위 `:root` 변수로 색 조정 |
| `favicon.svg` | 탭 아이콘 |

## 수정 방법

- **색상**: `style.css` `:root` 의 `--blue` `--gold` `--terra` `--cream` 수정
- **회사명·실적·연락처**: `index.html` 에서 교체 (현재 전부 예시값)
- **문양 제거**: `.lotus` / `.zigzag` 클래스가 붙은 `<div>` 삭제
- **세로 라벨 제거**: `.vlabel` 을 가로 라벨로 바꾸려면 `writing-mode` 줄 삭제
